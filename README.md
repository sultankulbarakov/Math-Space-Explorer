# Math Space Explorer

A fun and interactive space-themed educational game designed to help elementary/middle school students practice multiplication and division skills.

## 🚀 Features

- **Space Theme**: Explore different colorful planets while solving math problems
- **Progressive Difficulty**: Start with simple problems and advance to more challenging ones
- **Achievement System**: Earn achievements for streaks and quick answers
- **Time Challenges**: Face exciting time-based challenges every two levels
- **Reward System**: Collect crystals and earn points with streak multipliers
- **Visual Feedback**: Engaging animations and color changes for correct/wrong answers
- **Sound Effects**: Immersive audio feedback for all game actions
- **Responsive Design**: Playable on both desktop and mobile devices

## 🎮 Gameplay

- Solve multiplication problems to collect crystals
- Each level requires 5 crystals to complete
- Time challenges appear every 2 levels
- Build streaks for bonus points
- Quick answers earn time bonuses
- Different planets feature unique colors and challenges

## 🚦 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/math-space-explorer.git
```

2. Navigate to the project directory:
```bash
cd math-space-explorer
```

3. Run the game using a local server. You can use:
   - VS Code's Live Server extension
   - Python's HTTP server: `python -m http.server`
   - Node's http-server: `npx http-server`

4. Open your browser and navigate to the local server address (typically `http://localhost:8000`)
